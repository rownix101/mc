# 光照实现（第一阶段）

太阳方向与现有 20 分钟昼夜循环同步。每帧在主场景之前生成一张
2048×2048 Depth32Float 阴影图，覆盖以玩家为中心、光空间半径 96 格的区域。
光空间中心按纹素对齐，使用深度偏移、几何法线偏移和 3×3 PCF 比较过滤；
覆盖边缘平滑淡出。阴影只影响太阳直射光和太阳高光，环境光保留已有顶点 AO。
树叶和玻璃使用 atlas alpha 裁剪；水不投射不透明阴影，但水面太阳高光接受阴影。

实体表面使用 GGX 法线分布、相关 Smith 可见性和 Schlick Fresnel，
继续读取已有法线与粗糙度贴图。当前材质按非金属处理（F0=0.04），
太阳光与漫反射做能量分配；水下的程序化焦散也随直射光衰减。
模型参考：[Filament 材质系统](https://google.github.io/filament/Filament.md.html)。

限制：这是单级近景阴影，不是完整 CSM；只使用已加载网格中的遮挡物，
视距外的物体不投影。固定 PCF 过滤并不模拟距离相关的真实半影。
当前间接光结合半球近似、洪泛天光和低阶天空探针，尚无完整多次反弹 GI、GTAO 或 HDR 色调映射。
阴影每帧额外提交实体和透明网格各一次，阴影图约占 16 MiB；尚无性能基准。

验证：`cargo test --lib lighting_tests -- --nocapture` 检查太阳天顶/地平线/夜间
矩阵、亚纹素移动稳定性，并在可用 GPU 上创建与执行阴影和前向渲染管线。
无 GPU 的环境会明确跳过 GPU 检查。视觉验收需进入世界，对照树下、墙后、
玻璃镂空和水面高光，并观察移动时的阴影稳定性。


## 动态天空（2026-09-10）

天空使用程序化天顶渐变、朝向太阳的薄雾和局部晚霞，不再采样天空照片。
天顶和地平线颜色以线性空间设置；远景雾使用偏向天顶蓝色的地平线颜色。太阳、月亮使用
带屏幕空间抗锯齿的角直径圆盘，夜间淡入星点，水下保留独立的青色背景。

云使用稀疏天气网格中的不规则立体积云团：多个圆顶组成轮廓，三维噪声只用于
侵蚀边缘，避免薄层噪声被透视拉成长条。云团位于约 400–1280 的高度范围，
随风平移。视线最多推进 96 次，空白区域跳过较大距离，边缘和内部以 14 格步长
累计透射率；沿太阳方向的三次密度采样形成云内部遮光，远云融入地平线雾色。
这是有限预算的体积近似，不包含云对地形的投影，也不是完整的大气多重散射。
相较旧版 8 次薄层采样，片元工作量增加。`cargo test cumulus_gpu_benchmark --
--ignored --nocapture` 可测量 512×512 预览的 GPU pass 时间。RX 580 2048SP / Vulkan
本次测得 12 帧中位数约 1.16 ms；该数值只覆盖诊断 pass，不代表全屏游戏帧耗。

天空视线由逆投影后的远平面位置减去相机位置重建，在片元阶段归一化，
避免相机移动和网格原点切换造成天空偏移。昼夜沿用 20 分钟循环。
旧的 Poly Haven 素材及其署名仍保存在 `assets/sky/`，运行时不再加载。

验证：`cargo test sky_is_invariant_under_camera_relative_origin_changes` 检查原点切换；
`cargo test sky_preview_images -- --ignored` 输出白天、日落和夜间 GPU 渲染图至
`target/sky/`，用于检查云层、日月和地平线衔接。

## 水下丁达尔与树叶透光（2026-09-10）

主场景不透明合成之后增加一个加色全屏散射 pass：以几何太阳的屏幕位置为径向中心，
对场景颜色做 12 抽样径向模糊。水下启用合成焦散光源和更长的散射路径，得到类似
丁达尔效应的青色光柱；水面上则以树叶/地形与天空的亮度差作为遮挡源，让阳光从
叶隙间形成光束。片元在视角背向太阳或夜间时提前返回，绝大部分像素不会执行抽样。

树叶现在使用单独的 shader material 编码（`2`），仍然走 alpha-test 不透明路径并
投射 dappled 阴影；片元着色器在太阳位于叶片背面时按视线与太阳方向加一项带叶片
纹理色的透射光，让树冠有背光透亮的层次。水材质编码保持不变（`1`），玻璃仍为 `0`。

## 林地明暗与材质调整（2026-09-10）

探针方向性天光与逐顶点洪泛天光混合，探针贡献在体积边界平滑退回本地天光，
并由本地天光限制泄漏。背光侧面加入天空补光，下向面加入暖色地面反弹近似；
两者都随本地天光衰减，封闭处底值保持不变，全部间接光仍乘顶点 AO。
反弹不是对真实地表颜色的采样。保留现有 PCF、bias 和近景接触边缘，先通过
间接光改善大块投影的黑度，未增加阴影采样或新的全屏特效。

白天雾 extinction 从 0.003 降为 0.0018，夜间为 0.004；继续使用连续指数衰减，
雾色从地平线向天顶混合 22%，水下参数保持原值。白天 100 格距离的雾占比由
约 26% 降为 16%，200 格由约 45% 降为 30%。

草方块使用渲染材质编码 3（方块 ID 不变），只在顶面加入连续世界坐标低频色差，
已有 mip 法线细节增强 30%，粗糙度随斑块轻微变化；树叶编码 2 仍独立判断。
树木高度变为 4–7 格，冠幅两轴独立变化、厚度 3–4 层、外沿缺口率 10–25%，
高树根部少量加粗。所有树方块仍在主干水平两格查询范围内，确保跨列/LOD 一致。
程序化树形改变会影响旧种子重新生成的树；已保存的玩家方块编辑仍按原逻辑覆盖。

验证新增背光补光、封闭空间、接触 AO 的离屏 GPU 回归，以及树形确定性、无重复
方块和查询边界测试。采样优化参考 shader 同步间接光模型，保留独立的旧采样路径。
Present 的 CPU 等待时间不能当作 GPU 空闲率；本轮尚未测量完整游戏 GPU 帧耗，
画面效果仍需在同一相机位置进入世界对照。
